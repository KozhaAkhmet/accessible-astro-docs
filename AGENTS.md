# AGENTS.md

Astro 6 + Starlight docs site. Pages are MDX in `src/content/docs/`; live demos use `accessible-astro-components`. Verify every change with `npm run build`.

Read only the context files relevant to the task:

| File | Read when |
|---|---|
| `context/project.md` | setup, commands, env vars, folder layout, deployment |
| `context/pages.md` | adding a page, frontmatter, sidebar entries and badges |
| `context/page-template.md` | writing a component doc page (section skeleton) |
| `context/conventions.md` | writing style, MDX pitfalls, code style, commits, finish checklist |
| `context/styling.md` | global CSS helpers, `--sl-*` tokens, overriding demo styles |
| `context/customization.md` | rebranding leftovers, dead code, troubleshooting |
| `context/components/starlight.md` | Starlight built-ins (Aside, Tabs, Steps, FileTree, Card…) and code blocks |
| `context/components/icons.md` | `astro-icon` usage, installed icon sets |
| `context/components/library.md` | `accessible-astro-components` props cheat sheet, demo pattern, toasts |
| `context/components/site.md` | `src/components/*` (incl. `Drawio` diagrams), Starlight overrides |
